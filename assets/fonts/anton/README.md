# Cover display font

Anton Regular is bundled so Windows development and Linux production render
the same condensed cover lettering. Body and CTA typography are unchanged.

Source: https://github.com/google/fonts/tree/main/ofl/anton

The unmodified font is distributed with its SIL Open Font License in OFL.txt.
At 108 px, its visible capitals approximate the scale of the saved Wan cover;
the compositor positions the visible glyphs rather than font ascent metrics.
